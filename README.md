# 🚗⏰ Arduino Alarm Clock on Wheels
*An alarm clock that is designed to annoy you*

This project is part of my **iSTEM Assessment**, featuring an Arduino-powered alarm clock mounted on a base and wheels.  
When the alarm goes off, the clock *"runs away"*.

---

## 🛠️ Hardware Required
- **Arduino Uno**  
- **RTC_DS1307 RTC module**  
- **2× continuous servo motors**  
- **Buzzer**  
- **Ultrasonic distance sensor**

  YOU CAN MODIFY THE CODE TO FIT OTHER HARDWARE!!!!!

---

## 📁 How to Use
1. Copy and paste the provided code into the **Arduino IDE**  
2. Install all required **libraries/dependencies**  provided in the repository. 
3. Upload the sketch to your Arduino Uno
